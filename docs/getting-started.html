Getting started

Build and flash SATulator

Install PlatformIO, connect the ESP32-2432S028 board by USB, then run:

pio run -t upload
pio device monitor

First run

Connect the device to Wi-Fi when prompted. SATulator uses the configured public sources to retrieve price data. The startup screen is followed by the converter interface.

Daily use

The rate is expressed as fiat currency per one bitcoin; for example, 100000. Tap an input to enter an amount, and use the arrow button to switch conversion direction. Select bitcoin or satoshis as the output unit.

Changing the fiat currency does not download data. Use Refresh for the current currency, or Refresh all in Configuration.
