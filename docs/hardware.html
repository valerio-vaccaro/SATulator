Hardware

ESP32-2432S028 / CYD

The supplied PlatformIO environment targets the common ESP32-2432S028 2.8-inch Cheap Yellow Display (CYD): an ESP32 board with a 240 × 320 portrait ILI9341 display and XPT2046 touch controller.

Touch uses the portrait mapping defined by the firmware. The project is configured with a larger single application partition and has no OTA update path.
